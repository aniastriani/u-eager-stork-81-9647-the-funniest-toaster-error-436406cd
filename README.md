The funniest error message a kitchen toaster would show its owner, in
one line of at most 120 characters. An AI judge compares lines two at a
time and picks the funnier, fresher, tighter one.

## The entry

> ERROR 451: The bread has unionised. Browning suspended until the heat is addressed in writing.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes that single line
to `$MAKEFUN_OUTPUT_DIR/entry.txt` and prints it. Run it:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
